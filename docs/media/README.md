# Documentation media

These assets document two different things: the running Mac audio recorder and an early gift-opening design prototype.

## Native Mac app

- `app-idle.png`, `app-recording.png`, `app-saved.png`: actual public app states.
- `settings.png`: actual settings, with default shortcuts and a temporary demo output folder.
- `app-demo.mp4`: actual sequential native-window captures, about 6 seconds, 1080 × 860, H.264, no audio track.
- `app-demo.gif`: smaller animated preview of the same captures.

Captured on 2026-10-16. A generated tone drove the real recorder and meters. The recording itself is not included. Frames retain their capture timing; encoding repeats frames to provide a standard frame rate. The app has not been reconstructed or animated for this video.

The public app, its icon, and these app captures use macOS system lettering. No private trial-font wordmark or font file is included.

## Gift design prototype

- `gift-opening-preview.mp4`: a silent 6-second excerpt, 960 × 408.
- `gift-opening-preview.gif`: animated preview of that excerpt.
- `gift-wrapped.png`, `gift-tearing.png`, `gift-opened.png`: corresponding design stages.

Source: an earlier browser-based gift installer design exploration for Windows, originally named `Kol-Chen-Install-Preview.mp4`. It is not a capture of this Mac app being installed. The excerpt includes only the parcel, tearing paper, revealed concept box, and handwritten dedication. It excludes the original Windows installation options and completion screens.

The original 1024 × 800 frames were cropped to a 480 × 204 region at x=272, y=300; the video excerpt uses the first 6 seconds and is scaled to 960 × 408. The wrapper artwork is an AI-generated collage. Original photographic references and the rest of the experiment are not included.

There is currently no native Mac gift installer or notarized DMG in this repository. The README documents building from source as the available setup path.
